# RIYA 3D character assets

`RIYA.glb` is generated by the GitHub Actions workflow in `.github/workflows/build-riya-avatar.yml` from the open-source Ara 3D Gen character pipeline.

- Character data and generated human assets are based on MakeHuman CC0 1.0.
- The model is configured as an adult (25-year-old) female character with a dark long hairstyle, warm South Asian appearance settings, a dark tailored outfit, Mixamo-compatible game rig, facial expression shapes, and Oculus viseme shapes.
- The frontend adds the white apron and dark straps as meshes attached to the character's skeleton.
- To regenerate the model, edit `riya.params.json` and push the change to `main`; the workflow creates and commits `RIYA.glb`.
- The GLB is stored in this repository and served by the RIYA frontend. It is not downloaded from a paid avatar provider.

The generated model has fixed body proportions from the parameter file. It includes facial morph targets and speech visemes, but does not currently expose live bust/waist/hip sliders.
